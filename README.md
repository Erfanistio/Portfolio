# Nuxander React + Tailwind Portfolio

This is the React + Tailwind version of your provided HTML/CSS portfolio.

## Run it

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Components

All sections are split into components:

- `src/components/Loader.jsx`
- `src/components/Navbar.jsx`
- `src/components/Hero.jsx`
- `src/components/Projects.jsx`
- `src/components/About.jsx`
- `src/components/Services.jsx`
- `src/components/Journal.jsx`
- `src/components/Contact.jsx`
- `src/components/Footer.jsx`

Editable data lives in:

- `src/data/content.js`

## Assets

Put your real Figma exports in:

```text
public/assets/
```

Required names:

- `avatar.png`
- `hero.png`
- `placeholder.png`
- `fade.png`
- `about.png`
- `journal-1.png`
- `journal-2.png`
- `journal-3.png`
- `contact.png`
- `noise.png`

The project includes placeholder images so it can run immediately. Replace them with your final exported images.
